Đang chờ hai file

Chọn đủ hai file để bắt đầu so sánh tự động.

File chỉ được xử lý cục bộ trong trình duyệt và không được tải lên máy chủ. File lớn có thể cần thêm thời gian và bộ nhớ để tạo hash.
